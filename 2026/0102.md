## 내용

- **시니어 개발자는 주니어 대신 AI를 선택할까?**: 주니어 개발자는 팀과 함께 성장하며 AI가 할 수 없는 소프트 스킬과 팀 커뮤니케이션의 가치를 제공해야 한다. 코딩 기술만으로는 AI가 훨씬 효율적인 것이 현실.
  - [시니어 개발자는 주니어 대신 AI를 선택할까? | 요즘IT](https://yozm.wishket.com/magazine/detail/2932/)
- **Dead Framework Theory**: React가 더 이상 다른 프레임워크와 경쟁하는 것이 아니라 플랫폼이 되었으며, LLM 학습 데이터와 시스템 프롬프트 간의 자기 강화 피드백 루프로 인해 새로운 프레임워크가 도입되기 어려워지는 현상
  - [dead framework theory | AI Focus](https://aifoc.us/dead-framework-theory/)
- **React 컴포넌트 피라미드 스킴**: 재사용성을 과도하게 추구한 나머지 발생하는 과도한 엔지니어링 문제. DRY 원칙이 교리처럼 되어 복잡한 추상화와 prop soup를 만들어내는 함정에 빠지기 쉽다.
  - [The React Component Pyramid Scheme: An Over-Engineering Crisis | The New Stack](https://thenewstack.io/the-react-component-pyramid-scheme-an-over-engineering-crisis/)
- **툴팁 컴포넌트는 존재하지 말아야 한다**: 툴팁을 별도의 저수준 컴포넌트로 제공하기보다는 Button, IconButton, InfoIcon 같은 고수준 패턴 컴포넌트에 통합하여 일관된 UX와 접근성을 보장해야 한다
  - [Tooltip Components Should Not Exist | TkDodo's blog](https://tkdodo.eu/blog/tooltip-components-should-not-exist)
- **Your URL Is Your State**: URL을 상태 관리 도구로 활용하는 방법. URL은 공유 가능성, 북마크 기능, 브라우저 히스토리, 딥 링크 등의 이점을 제공하며, 웹의 가장 오래된 상태 관리 솔루션이다
  - [Your URL Is Your State | Ahmad Alfy](https://alfy.blog/2025/10/31/your-url-is-your-state.html)
- **CSS Custom Highlight API**: JavaScript로 Range 객체를 생성하고 CSS로 스타일링할 수 있는 텍스트 강조 API. DOM 구조를 변경하지 않고도 검색 결과나 선택된 텍스트를 사용자 정의 스타일로 강조할 수 있다
  - [CSS Custom Highlight API - Web APIs | MDN](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API)
- **React 클라이언트와 서버 DTO 사이의 경계 설정하기**: 서버 DTO를 그대로 사용할지 클라이언트 도메인 타입으로 변환할지에 대한 논의. 대규모 프로젝트나 여러 API를 사용하는 경우 변환 레이어를 통해 서버 변경에 대한 격리와 타입 안전성을 확보할 수 있다
  - [React 클라이언트와 서버 DTO 사이의 경계 설정하기 | Velog](https://velog.io/@yunsungyang-omc/React-%ED%81%B4%EB%9D%BC%EC%9D%B4%EC%96%B8%ED%8A%B8%EC%99%80-%EC%84%9C%EB%B2%84-DTO-%EC%82%AC%EC%9D%B4%EC%9D%98-%EA%B2%BD%EA%B3%84-%EC%84%A4%EC%A0%95%ED%95%98%EA%B8%B0)

  - [Claude-Mem - Your AI's Perfect Memory Archive](https://claude-mem.ai/)

  - [Conductor - Run a team of coding agents on your Mac](https://www.conductor.build/)
