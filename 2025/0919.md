- **-apple-visual-effect**
  - Apple은 iOS 26에서 도입한 Liquid Glass 디자인 효과를 웹 콘텐츠에 적용할 수 있는 비공식 CSS 속성 `-apple-visual-effect`를 도입
  - `-apple-system-glass-material` 값을 사용하여 투명하고 반투명한 유리 질감의 시각 효과를 구현
  - 웹에서 직접 사용할 수 없으며, WKWebView 환경에서만 제한적으로 적용 가능
  - [Apple has a private CSS property to add Liquid Glass effects to web content](https://alastair.is/apple-has-a-private-css-property-to-add-liquid-glass-effects-to-web-content/)

- **Gaussian Blur**
  - **Box Blur**
    - 픽셀 주변 일정 영역을 잡고, 그 영역 내 모든 픽셀 값을 단순히 평균 내서 새로운 픽셀로 만드는 방식
    - 장점: 계산이 단순함
    - 단점: 경계가 뭉툭하고 투박하게 흐려진 느낌
  - **Gaussian Blur**
    - 가까운 픽셀일수록 더 큰 가중치를, 먼 픽셀일수록 더 작은 가중치를 주어 계산
    - 장점: 자연스러운 블러 효과
    - 단점: 연산량 많음
  - **Fast Gaussian Blur(Stack Blur)**
    - Box Blur를 3~4회 연속 적용하면 Gaussian Blur와 거의 동일한 효과를 얻을 수 있음
  - 웹 브라우저에서 제공하는 CSS `blur()` 함수는 내부적으로 가우시안 블러를 사용
  - [CSS blur 한 줄 뒤에 숨은 가우시안 블러의 세계](https://all-dev-kang.tistory.com/entry/CSS-blur-%ED%95%9C-%EC%A4%84-%EB%92%A4%EC%97%90-%EC%88%A8%EC%9D%80-%EA%B0%80%EC%9A%B0%EC%8B%9C%EC%95%88-%EB%B8%94%EB%9F%AC%EC%9D%98-%EC%84%B8%EA%B3%84)
